# Limitations and publication rights

This release provides synthetic demonstration and archival CSV replay with an authorized external model. It omits the frozen coefficient and seasonal profile bundle, private datasets and ledgers, archived source-event inputs, and the private end-to-end historical runner. No applicable redistribution grant for those materials was identified. The original model identities and aggregate study results are included as provenance.

The synthetic mode uses its own identity. Archival replay uses a separate protocol identity and leaves actual receipt and commitment fields unset. LATE01's archived quote events and hypothetical commitments are a separate retrospective protocol. This package contains no prospective issuer, order execution or broker integration. Its results establish neither trading profitability nor prospective forecasting superiority.
